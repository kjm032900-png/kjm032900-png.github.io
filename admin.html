홈페이지 콘텐츠 관리

차량 가격과 프로모션, 표시 연월 및 관련 안내 문구는 content.json 한 곳에서 관리합니다. 홈페이지는 이 파일을 읽어 표시합니다. 별도 로그인 서버 없이 GitHub 계정과 저장소 권한으로 수정하는 방식입니다.

프로모션·차량·소개 글 수정

아래 버튼을 누른 뒤 GitHub에서 content.json 파일의 연필(편집) 버튼을 누르세요. 아래 항목을 수정하고 JSON 문법을 확인한 뒤, 변경 내용을 검토해 저장하세요. GitHub에 저장하면 기존 배포 설정에 따라 공개 사이트에 반영될 수 있습니다.

내용 수정하러 가기

수정 항목 안내

  • models: 차량의 price는 쉼표·원 표시 없는 원 단위 숫자입니다. 예: 77500000. 가격 미정은 문자열이 아닌 null로 입력합니다. 분류·모델군·연식·트림명·출처와 순서를 임의로 삭제하지 마세요.
  • promotions: 월별 프로모션의 가격, 현금 혜택(cash), 금융 혜택(mbf), 설명을 수정합니다. 프로모션 가격은 별도 안내값이므로 차량 가격 변경 시 함께 확인하세요.
  • display.year / display.month: 표시 연도와 월을 숫자로 입력합니다. 연결된 메뉴·제목·첫 화면·프로모션·하단의 월 표시가 함께 바뀝니다.
  • copy: 관련 안내 문구와 검색 설명입니다. {year}, {month}, {month_en}, {source_date_dot}, {source_book_month}는 자동 치환되므로 필요한 자리에 유지하세요. HTML 태그 대신 일반 텍스트를 입력하세요.
  • source_book_month: 어프로치북 자료의 월(1~12), source_date: 가격표 기준일, updated: 데이터 수정일입니다. YYYY-MM-DD 형식으로 입력합니다. 표시 월을 바꿔도 공식 자료 기준일은 자동으로 바뀌지 않습니다.
  • promotion_note: 프로모션 자료 기준 메모입니다. 현재 화면에 자동 노출되지는 않으므로, 고객 안내는 copy와 프로모션 설명도 함께 확인하세요.
  • card_prices: 신차 카드가 참조할 모델군·연식·트림명과 시작가 여부(starting)입니다. 가격 숫자를 복사하지 않고 models의 해당 가격을 사용합니다. 참조 차량을 변경·삭제할 때 함께 확인하세요.
  • images는 모델군별 사진 연결, benefits는 구매 혜택 설명입니다. 기존 연결을 보존하세요. 전화·문자 상담 번호는 이번 작업에서 변경할 필요가 없습니다.

월만 변경해도 트림 연식·할인 조건·자료 출처가 자동 갱신되지는 않습니다. 실제 자료를 확인한 항목만 수정하세요. JSON에는 주석이나 마지막 항목 뒤 쉼표를 넣을 수 없습니다.

맞춤 차량 공유 및 CRM 연동 관리

전 차종에서 트림을 여러 개 선택해 share.html?ids=차량ID1,차량ID2 주소를 만들 수 있습니다. 기존 가격·프로모션 정보는 content.json을 그대로 사용합니다.

모델별 공식 카탈로그 PDF 주소를 바꾸려면 아래 catalog-links.json 파일의 catalogs 항목에서 해당 차종의 url을 수정하세요. 링크가 확인되지 않은 경우 null로 두면 공식 카탈로그 목록으로 안내됩니다. URL은 실제 벤츠코리아 공식 HTTPS 주소만 사용하세요.

수정 후 확인

GitHub에 저장한 내용의 배포·캐시 반영에는 시간이 걸릴 수 있습니다. 반영 후 페이지를 새로고침하고 차량 목록·프로모션·신차 카드 가격·월 표시·검색·상세정보를 확인하세요. 로컬 확인은 파일을 직접 여는 대신 HTTP 서버를 사용하세요.

JSON 로딩이나 검증에 실패하면 가격을 숨기고 오류 안내를 표시합니다. 전화·문자 상담은 계속 사용할 수 있습니다. 오류가 생기면 JSON 문법, 필수 항목, 숫자 가격과 카드 참조를 확인하고, 해결되지 않으면 GitHub 변경 이력의 정상 데이터를 참고해 복구하세요.

공개 홈페이지 확인
주의: 관리자 화면은 비밀번호로 보호되는 독립 CMS가 아닙니다. GitHub 로그인 및 저장소 권한이 있어야 실제 수정할 수 있습니다. 이 화면의 링크 자체는 공개되어도 계정 권한을 부여하지 않습니다.
